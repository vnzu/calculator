# REQUIREMENTS

This calculator should allow the user to use the following mathematic operations:
1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Exponentiation

It should also properly handle the following:
1. Division by 0

It should be able to perform calculations such as:
1. `2 + 5`
2. `9 - 4`
3. `2 * 7`
4. `27 / 3`
5. `3 ^ 7`
